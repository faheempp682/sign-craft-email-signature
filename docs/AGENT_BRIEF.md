## The product in one paragraph
SignCraft: a Next.js 15 (App Router, React 19, TypeScript, Tailwind 4, zod 4) email-signature builder on Supabase (auth, Postgres, RLS). A signature is a JSON document (`lib/schema/document.ts`) rendered to Outlook-safe table HTML by `lib/renderer`. Roles are member < designer < admin; feature flags and per-user AI limits live in the database (`lib/authz/*`, migration 0003). Gmail push exists (`lib/google/*`). It is an internal tool first; the public marketing site is optional and OFF unless `PUBLIC_SITE_ENABLED=true`.

Validate all input with zod. Fail closed. Never send secrets, tokens or other users' data to the browser. Never log personal content.

## Environment quirks (Windows, Git Bash)
- Use `npm`, not pnpm. Tests: `npx vitest run <path>`. Lint: `npx eslint <path>`.
- Shell heredocs break when the text contains apostrophes or backslashes, and shell variables are unreliable. **Create files with the Write tool.** For edits to existing files use the Edit tool, or a short Python script with explicit paths.
- Native Grep and Glob are denied by policy: use `mcp__lean-ctx__ctx_search`, `ctx_glob`, `ctx_tree`, and `ctx_read` (the native Read tool is flaky). `ctx_shell` or Bash for commands. Pipelines containing certain words can be rejected by the shell allowlist: split them.
- Files may have CRLF line endings; keep a file's existing style.
- Use the scratchpad folder you are given for temporary files, not `/tmp`.
